# Nikita Sawant — APAC ServiceNow Delivery Portfolio

A responsive personal portfolio site highlighting APAC ServiceNow delivery leadership.

## Run locally

Open `index.html` in a browser. The page uses the local `style.css` and `script.js` files and has no build dependencies.

## GitHub Pages

The workflow in `.github/workflows/pages.yml` deploys the static site to GitHub Pages when changes are pushed to `main`. It can also be started manually from the repository's Actions tab.

## Portfolio data

The delivery metrics, program names, regional counts, and milestones shown are illustrative placeholders. Replace them with accurate information approved for public sharing before presenting them as actual portfolio results.
